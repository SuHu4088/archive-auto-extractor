# 常见问题 (FAQ)

## 安装与运行

### Q: 启动时报「7z.exe not found」
A: 7-Zip 未安装或路径不符。打开「工具 → 设置」，在「7z.exe 路径」选择正确的 `7z.exe`。默认路径 `D:\hardware\7-Zip\7z.exe`，可从 [7-zip.org](https://7-zip.org) 下载安装。

### Q: 启动时报缺少 PyQt6
A: 运行 `pip install -r requirements.txt`，或单独 `pip install PyQt6`。本机已预装，新环境需手动安装。

### Q: 程序无法启动，提示 DLL 缺失
A: 确保 Python 与系统位数一致（建议 64 位）。PyQt6 需要匹配的 VC++ 运行库，Windows 通常已自带。

## 使用

### Q: 为什么受密码保护的压缩包被跳过了？
A: 这是设计行为（需求 3）。默认密码模块关闭，避免无谓尝试。在「工具 → 设置」勾选「启用密码库」，然后通过「工具 → 密码库」添加密码，即可自动尝试解密。

### Q: 密码尝试全部失败后压缩包去哪了？
A: 会被移动到解压输出目录下的 `password_protected_unsolved/` 子文件夹，并在状态日志显示「已尝试所有密码仍无法打开」。可在设置中改为「压缩包所在目录」。

### Q: 解压后的文件在哪？
A: 在解压输出目录下与压缩包同名的子文件夹中。例如 `data.zip` 解压到 `<输出目录>/data/`。可在设置中关闭「同名子文件夹」改为直接解压到输出根目录。

### Q: 原始压缩包会被删除吗？
A: **默认不会**。只有同时满足以下条件才删除：
1. 在设置中开启「CRC 校验通过后删除原压缩包」。
2. 解压成功且 CRC 校验通过。
3. 弹出确认对话框时点击「是」（除非关闭了确认）。

删除优先送入回收站（需 `send2trash` 包），可从回收站恢复。

### Q: CRC 校验失败怎么办？
A: 校验失败时原文件保留，状态标记为「失败」，日志显示具体原因（如 crc-mismatch、size-mismatch、7z-t 退出码）。可能是下载损坏或磁盘错误，建议重新获取压缩包。

## 密码库

### Q: 密码库文件在哪？
A: 在 `~/.archive_password_vault/passwords.json`（即 `C:\Users\<用户名>\.archive_password_vault\`），**位于项目文件夹外部**，避免被项目 Git 误收。

### Q: 密码库会被 Git 追踪吗？
A: 会。密码库是独立的 Git 仓库（`~/.archive_password_vault/.git`），每次增删改查、开启/关闭会话都会自动提交带描述性消息的提交，可在「密码库」对话框底部查看提交记录。项目仓库与密码库仓库完全独立。

### Q: 忘记某个密码怎么办？
A: 在「密码库」对话框中删除该条目（需二次确认），或取消勾选「启用」暂不尝试。删除操作也会被 Git 记录。

### Q: 密码会明文显示吗？
A: 默认掩码显示 `•••••`。可在密码库对话框勾选「显示密码明文」临时查看。

### Q: 密码尝试的顺序是怎样的？
A: 按启用 → 历史成功次数降序 → 最近使用时间降序 排序。曾成功解压过的密码会优先尝试。

## 兼容性

### Q: 支持哪些压缩格式？
A: ZIP、RAR（含 RAR5）、7Z。AES 加密的 ZIP、头部加密的 RAR5/7Z 均通过 7z.exe 统一处理。

### Q: 支持 RAR 吗？需要 WinRAR 吗？
A: 支持 RAR 解压，**不需要** WinRAR。7z.exe 自带 RAR 解压能力。仅需安装 7-Zip。

### Q: 支持分卷压缩包吗？
A: 当前版本按单个压缩包处理，分卷需先合并。未来版本可能支持自动识别分卷。

### Q: 一次能处理多少个压缩包？
A: 无硬性上限，逐个串行处理。每个压缩包在 GUI 中实时显示进度与状态。可随时点击「停止」在当前文件处理完后中止。

## 安全

### Q: 密码库安全吗？
A: 密码以 JSON 明文存储于用户目录，依赖操作系统账户隔离保护。**这不是加密保险库**，适合个人本地使用。若需高安全性，建议配合磁盘加密（如 BitLocker）。所有变更有 Git 审计追踪。

### Q: 删除密码会真的删除吗？
A: 是，需两步确认（准备令牌 + 确认对话框）。删除后 Git 历史仍保留旧版本，可从 Git 历史恢复（需手动操作）。
